# History Forge Licensing

History Forge uses a layered licensing model. Different components have
different rights, and no label silently overrides an earlier public grant.

| Component | License or status |
|---|---|
| Application code, visualization engine, schemas, build tools and tests | [Apache License 2.0](LICENSE) |
| Forge-owned structured data and annotations already released in this public preview | Apache License 2.0; the existing grant is preserved |
| Future original editorial data expressly identified in a Release Notice | [History Forge Data License 1.0](HISTORY_FORGE_DATA_LICENSE.md) |
| Historical source text, translations, images and third-party data | The source-specific terms in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) and the relevant release manifest |
| Commercial agent training on designated History Forge Data License material | Separate written agreement; see [Commercial agent-training licensing](COMMERCIAL_AGENT_TRAINING.md) |
| History Forge and Titans Forge names, marks and logos | Not licensed except for accurate identification and required attribution |

## Current Public Preview

The existing Forge-owned code, structured data and annotations in this public
preview remain available under Apache-2.0. The History Forge Data License does
not retroactively revoke, narrow or replace that grant. Public-domain historical
material and third-party material remain governed by their independent status
and notices.

No file in the current preview becomes Covered Material under the History Forge
Data License merely because that license is present in the repository. A future
data release must include an explicit Release Notice and component-level rights
manifest identifying the new contribution, version and immutable hashes. If the
designation is missing or ambiguous, the new data license supplies no grant and
does not withdraw any other available permission.

## Future Data Releases

History Forge may designate new, rights-controlled editorial contributions under
the History Forge Data License 1.0. That community license permits personal use,
teaching, genuine noncommercial scholarship, noncommercial research training and
limited attributed excerpts. Commercial agent training and commercial bulk-data
products require separate written permission, except where another license or
applicable law already permits the activity.

Historical facts, names, ideas and public-domain expression are not made
exclusive. Third-party source material is never relicensed merely because it is
described, cited or packaged by History Forge.

## Contributions

The repository's Apache-licensed software contribution rule remains unchanged.
Do not submit historical source text, modern translations, images or proprietary
datasets unless you have authority to do so and identify their exact terms.
Inclusion in an issue or pull request does not assign ownership to Titans Forge
or guarantee that material will be accepted into a data release.

This scope map is explanatory. The applicable license and release-specific
notices control.
